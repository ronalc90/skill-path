## Sobre el Proyecto

SkillPath ofrece rutas estructuradas para carreras tecnologicas con:

- **4 rutas** curadas (Backend Java, Frontend React, Data Python, Mobile Flutter)
- **27 hitos** con recursos de aprendizaje
- **Motor de evaluacion** con quizzes y scoring automatico
- **Dashboard** con metricas de progreso
- **API RESTful** en Go con Clean Architecture
