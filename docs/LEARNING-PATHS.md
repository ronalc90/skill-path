# Rutas de Aprendizaje

SkillPath incluye 4 rutas de aprendizaje pre-cargadas, cada una disenada para cubrir una carrera tecnologica completa desde los fundamentos hasta temas avanzados.

---

## 1. Backend Developer con Java

**Slug:** `backend-developer-java`
**Categoria:** Backend
**Dificultad:** Intermedio
**Duracion estimada:** 120 horas

### Descripcion
Ruta completa para convertirse en desarrollador backend con Java. Cubre desde los fundamentos del lenguaje hasta arquitecturas de microservicios y despliegue en la nube.

### Hitos

| # | Hito | Horas | Temas Clave |
|---|------|-------|-------------|
| 1 | Fundamentos de Java | 15h | Variables, tipos de datos, control de flujo, POO, colecciones |
| 2 | Spring Boot Essentials | 20h | Configuracion de proyectos, inyeccion de dependencias, REST APIs, testing |
| 3 | Bases de Datos con JPA/Hibernate | 15h | Mapeo objeto-relacional, consultas JPQL, transacciones, migraciones |
| 4 | Seguridad con Spring Security | 15h | Autenticacion, autorizacion, JWT, OAuth2 |
| 5 | Testing y Calidad de Codigo | 12h | JUnit 5, Mockito, tests de integracion, cobertura |
| 6 | Microservicios | 18h | Patrones de microservicios, comunicacion entre servicios, service discovery |
| 7 | Docker y Kubernetes | 15h | Contenedores, imagenes, Docker Compose, orquestacion |
| 8 | CI/CD y Despliegue | 10h | Pipelines, GitHub Actions, monitoreo, observabilidad |

### Recursos Destacados
- **Cursos:** Java Programming Masterclass (Udemy), Microservices with Spring Cloud
- **Libros:** Effective Java (Joshua Bloch), Building Microservices (Sam Newman), Spring Security in Action
- **Documentacion:** Spring Boot Reference, Baeldung tutorials
- **Ejercicios:** Spring PetClinic project

## Estructura de Recursos

Cada recurso incluye:

| Campo | Descripcion |
|-------|-------------|
| `title` | Nombre del recurso |
| `url` | Enlace directo |
| `type` | Tipo: `course`, `book`, `video`, `tutorial`, `article`, `exercise` |
| `provider` | Plataforma (Udemy, YouTube, Baeldung, etc.) |
| `is_free` | Si es gratuito o de pago |
| `estimated_minutes` | Tiempo estimado de consumo |
| `order_index` | Orden sugerido dentro del hito |

## Criterio de Seleccion

Los recursos fueron seleccionados siguiendo estos criterios:
1. **Calidad** - Contenido actualizado y bien valorado por la comunidad
2. **Variedad** - Mix de formatos (video, texto, ejercicios)
3. **Accesibilidad** - Prioridad a recursos gratuitos cuando estan disponibles
4. **Progresion** - Ordenados de menor a mayor complejidad dentro de cada hito
